# Claude Code Rules for House of Novels

## Git & Commits

- Do NOT commit changes unless explicitly asked by the user
- Do NOT include "Claude Code", "Co-Authored-By: Claude", or any Claude attribution in commit messages
- Do NOT push to remote unless explicitly asked
- Do NOT amend commits unless explicitly asked
- Do NOT use `--force` or destructive git commands unless explicitly asked

## General Behavior

- Wait for user approval before making significant changes
- Ask before deleting files or making destructive operations
- Do not automatically run tests or builds unless asked
- Prefer editing existing files over creating new ones
